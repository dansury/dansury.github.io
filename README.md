# Портфолио — Яна Павленко

Личный сайт-портфолио: одиннадцать продуктов с продуктовым разбором каждого
(проблема → решение → для кого → что даёт бизнесу → что переносится дальше),
на русском и английском.

**→ https://dansury.github.io/PORTFOLIO/**

## Что внутри

Статическая страница без сборки и внешних библиотек — открывается двойным
кликом, разворачивается на GitHub Pages как есть.

```
index.html              разметка и мета (OG, JSON-LD Person)
assets/css/style.css    графит + белое; шаг сетки и шкала кегля — Фибоначчи
assets/fonts/           Electrolize (кириллическая версия), woff2, 18 КБ
assets/js/motion.js     пружины, единый rAF-тикер, reveal со stagger
assets/js/phi.js        золотое сечение на canvas (см. ниже)
assets/js/fiber.js      генеративная лента нитей вместо фотографии
assets/js/data.js       весь контент: проекты, факты, стек, словарь RU/EN
assets/js/app.js        рендер, язык, фильтры, скролл-хром
assets/img/             фото, иконка
```

### Золотое сечение — не картинка, а программа

`assets/js/phi.js` строит фигуру рекурсивно. Единица построения — золотой
прямоугольник φ × 1; если отрезать от него квадрат, останется такой же
прямоугольник, повёрнутый на 90° и уменьшенный в φ раз:

```
шаг = translate(φ, 0) · rotate(90°) · scale(1/φ)
```

У этого преобразования есть единственная неподвижная точка — «глаз» спирали.
Она вычисляется, а не подбирается (`EYE_X`, `EYE_Y`), и закрепляется в золотой
точке экрана: 61.8 % по ширине, 38.2 % по высоте.

Прокрутка управляет двумя величинами:

- **zoom** — непрерывное падение в глаз спирали. За страницу проходится 10.5
  целых φ-шагов; на каждом шаге окно уровней сдвигается на единицу, поэтому
  фигура самоподобна и не заканчивается.
- **detail** — сколько уровней строится (7 → 18) и насколько подробно: линии
  разреза квадратов рисуются всегда, числа Фибоначчи проступают по мере
  углубления.

Обе величины идут через пружины из `motion.js`, поэтому у фигуры есть инерция.
Прозрачность уровня считается по его размеру на экране, а не по индексу — это
и делает сдвиг окна незаметным.

### Лента нитей

`assets/js/fiber.js` рисует то, что раньше было фотографией: около двухсот
нитей, намотанных на невидимое раскрытое кольцо. Форма нигде не описана — объём
возникает там, где накладываются десятки слабых нитей, как в проволочной
скульптуре. Каждая нить идёт по гладкому шуму (две октавы) плюс общий
низкочастотный поток, который сбивает соседние нити в пучок. Геометрия
считается один раз; кадр только вращает и проецирует её.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000
```

## Публикация

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.

## Правки контента

Всё в `assets/js/data.js`: словарь интерфейса (`i18n`), цифры первого экрана
(`facts`), колонки стека (`stack`) и массив проектов (`projects`). У каждого
проекта два языковых блока одинаковой формы, так что новый проект добавляется
одним объектом.

## Доступность и производительность

`prefers-reduced-motion` выключает анимацию, спираль и лента нитей замирают;
раскрытие карточек работает с клавиатуры (`aria-expanded` + `inert` на скрытой
панели); контраст текста ≥ 4.5:1, тач-таргеты ≥ 44 px; изображение отдаётся в
WebP с JPEG-фолбэком; внешних библиотек нет, весь JS — около 25 КБ.
